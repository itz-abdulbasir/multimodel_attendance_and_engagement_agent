## 1. Executive Summary & Objective

In **Activity 4.2: Multimodal Signal Fusion**, signals generated by the Vision Module and Audio Module are synchronized and aggregated into a unified, extensible data representation. Visual indicators—such as presence duration, movement patterns, and inactivity periods—are aligned with corresponding audio indicators, including calibrated noise levels and speech activity, using timestamp-based synchronization.

The fusion process guarantees that both modalities contribute proportionally to engagement understanding. By correlating visual attention cues with audio interaction levels, the system captures a more accurate picture of classroom dynamics than single-modality analysis. This combined representation forms the foundational input for higher-level reasoning, scoring mechanisms, and real-time instructional interventions.

The fused data structure was engineered with an extensible architecture, allowing supplementary sensory modalities (e.g., smart whiteboard telemetry, physiological wristband biosensors, student clicker polls) to be seamlessly incorporated in future enhancements without altering downstream schemas.

### 3.1 AI Suggestion Engine (`backend/core/ai_suggestions.py`)
Directly implemented from the reference image, [`AISuggestionEngine`](file:///c:/Users/91970/OneDrive/Music/SmartBridge/backend/core/ai_suggestions.py) generates natural language pedagogical interventions by correlating visual attention cues with audio interaction levels.

```python
class AISuggestionEngine:
    def __init__(self, api_key: Optional[str] = None, model: str = "llama3-8b-8192"):
        self.api_key = api_key or os.getenv("GROQ_API_KEY", "")
        self.model = model
        self.client = Groq(api_key=self.api_key) if self.api_key and GROQ_AVAILABLE else None

    def generate_suggestions(self, session_data: dict) -> List[Dict[str, Any]]:
        prompt = self.build_prompt(session_data)
        try:
            if not self.client:
                return self._fallback_suggestions(session_data)

            completion = self.client.chat.completions.create(
                messages=[
                    {"role": "system", "content": "You are an expert AI teaching assistant."},
                    {"role": "user", "content": prompt}
                ],
                model=self.model,
                temperature=0.7,
                max_tokens=200
            )
            response = completion.choices[0].message.content
            return self._parse_response(response)
        except Exception as e:
            print(f"AI Suggestion Error: {e}")
            return self._fallback_suggestions(session_data)
```

#### Deterministic Offline Fallback Matrix
To uphold the **100% offline edge privacy guarantee**, the engine provides deterministic, contextual heuristic suggestions if the network or Groq token is unavailable:
1. **Room Acoustic Reset:** Triggered when ambient noise is `LOUD_DISRUPTIVE` or $\ge 75\text{ dB SPL}$. Pauses lecture to regain acoustic focus.
2. **Interactive Scaffolding Check:** Triggered during `QA_INTERACTION` when visual focus is high ($\ge 65\%$) but turn-taking stagnates ($<0.8\text{ turns/min}$).
3. **Visual Re-Engagement Reset:** Triggered when the room is quiet ($<52\text{ dB SPL}$) but student visual gaze drifts below $55\%$.
4. **Physical Alertness Boost:** Triggered on prolonged physical stillness (inactivity $\ge 90\text{s}$, motion $<0.02$). Recommends a quick stand-up stretch or poll.
5. **Pacing Adjustment for Restlessness:** Triggered on elevated physical fidgeting (motion $>0.40$) with declining attention.
6. **Instructional Flow Maintenance:** Recommends maintaining pace when visual and acoustic dynamics are in harmonious balance.

### 3.3 Movement Pattern & Posture Classification Logic
Movement energy ($M \in [0.0, 1.0]$) extracted from optical frame differences and centroid tracking is mapped to discrete behavioral states:
- **`STATIC_DORMANT` ($M < 0.02$):** Prolonged physical stillness without note-taking or posture adjustments. Penalizes motion score ($S_{mot} = 0.40$).
- **`FOCUSED_STABLE` ($0.02 \le M \le 0.25$):** Ideal posture indicating active note-taking, attentive head nodding, and forward visual focus. Receives optimal motion score ($S_{mot} = 0.95$).
- **`ELEVATED_ACTIVE` ($0.25 < M \le 0.45$):** Purposeful classroom activity, group alignment, or board interaction ($S_{mot} = 0.70$).
- **`RESTLESS_JITTER` ($M > 0.45$):** Excessive physical fidgeting, chair shifting, and wandering posture. Penalizes motion score ($S_{mot} = 0.35$).

### 3.4 Cross-Modal Correlation & Coherence Analysis
1. **Pearson Correlation ($r$):**
   Calculated over a rolling 30-sample sliding buffer between normalized visual attention ($v_i$) and normalized audio interaction ($a_i$):
   $$r = \frac{\sum_{i=1}^n (v_i - \bar{v})(a_i - \bar{a})}{\sqrt{\sum_{i=1}^n (v_i - \bar{v})^2 \sum_{i=1}^n (a_i - \bar{a})^2}}$$
2. **Pedagogical Coherence Score ($C \in [0.0, 1.0]$):**
   Evaluates whether visual and audio channels reinforce the intended teaching phase:
   - In `INSTRUCTOR_MONOLOGUE`: High coherence ($0.90$) occurs when visual gaze is focused on the board ($v \ge 0.70$) and ambient noise is low ($<60\text{ dB SPL}$). Low coherence ($0.30$) indicates simultaneous visual wandering and room chatter.
   - In `QA_INTERACTION`: High coherence ($0.95$) occurs when visual gaze is active ($v \ge 0.65$) and student verbal turn-taking is frequent ($a \ge 0.60$).
